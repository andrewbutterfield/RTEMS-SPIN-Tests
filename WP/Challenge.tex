\section{The Challenge}

Partial Pre/Post-Conditions + C Tests to Formal API Semantics

\subsection{Example: Integer Div/Mod}

Laws of mod/div for integers in programming languages (e.g. Haskell):

\begin{eqnarray*}
   n \div (-d)    &=& -(n \div d)
\\ (-n) \div d    &=& -(n \div d)
\\ (-n) \div (-d) &=& n \div d
\end{eqnarray*}

\begin{eqnarray*}
   n \mod (-d)    &=& -(n \mod d)
\\ (-n) \mod d    &=& n \mod d
\\ (-n) \mod (-d) &=& -(n \mod d) 
\end{eqnarray*}

\def\abs#1{|{\!#1\!}|}


To reason about the above we also need absolute values ($\abs{\_}$).
\begin{eqnarray*}
   \abs n  &=& -n, \qquad n < 0
\\         &=& n, \qquad \text{otherwise}
\end{eqnarray*}

We assume that we know about integer arithmetic and comparisons.

We have preconditions regarding the ``zeroness`` of the divisor,
and the sign of both inputs. The sign-function can establish these.
We can express postconditions in terms of 
the absolute values and signs of the inputs.

We want a collection of disjoint and exhaustive
pre-conditions whose disjunction evaluates to true.

\newpage

\subsection{Specifying $\div$}

\subsubsection{Preconditions}

Those regarding $n$:
\begin{eqnarray*}
   \pre n &=& \setof{NZ,NP,NN}
\\ NZ &\defs&  n = 0
\\ NP &\defs&  n > 0
\\ NN &\defs&  n < 0
\end{eqnarray*}

Those regarding $d$:
\begin{eqnarray*}
   \pre d &=& \setof{DZ,DP,DN}
\\ DZ &\defs&  d = 0
\\ DP &\defs&  d > 0
\\ DN &\defs&  d < 0
\end{eqnarray*}

\subsubsection{Postconditions}

We assume function $\div'$ works correctly on positive numbers. 
\begin{eqnarray*}
   \post\div &=& \setof{UNDEFDIV,ISDIV,NEGDIV}
\\ n \div d &=& r
\\ UNDEFDIV &\defs& r = \bot 
\\ ISDIV    &\defs& r = \abs n \div' \abs d  
\\ NEGDIV   &\defs& r = -(\abs n \div' \abs d) 
\end{eqnarray*}

\subsubsection{Transitions}

\begin{eqnarray*}
   \pre{n}\times\pre{d} &\then& \post\div
\\ (\_,DZ) &\then& UNDEFDIV
\\ (NP,DP) &\then& ISDIV
\\ (NN,DP) &\then& NEGDIV
\\ (NP,DN) &\then& NEGDIV
\\ (NN,DN) &\then& ISDIV
\end{eqnarray*}

\subsection{Testing $\div$}

Given a map from $(preN,preD)$ to $post$,
we generate test code that generates code to:
\begin{itemize}
   \item initialise $n$ and $d$ that satisfies $preN \land preD$
   \item run $\div$ with $n$ and $d$ as input, writing its results to $r$.
   \item check that the value of $r$ is correct.
\end{itemize}

\subsubsection{Test Preconditions}

Since the precondition is based on the signs to the numbers,
we shall introduce symbolic test inputs $N$ and $D$, 
that are both non-negative:
$$ N \geq 1 \land D \geq 1$$
We use these because while it is necessary 
to use concrete values in actual tests 
($n=7 \land d =2$, say),
we need need our derived semantics to cover all possible values involved.

The preconditions are implemented by assignments that ``make them so'':
\begin{eqnarray*}
   NZ &\refinedby& n := 0
\\ NP &\refinedby& n := N
\\ NN &\refinedby& n := -N
\\ DZ &\refinedby& d := 0
\\ DP &\refinedby& d := D
\\ DN &\refinedby& d := -D
\end{eqnarray*}
We then execute $r := n \div d$ 
after the above initialisations have been done.

\newpage
\subsubsection{Postcondition Tests}

We then run the following test:
$$test(r,\post\div)$$
The actual behaviour of a real test of the form $test(a,e)$ is:
\begin{eqnarray*}
   && \ifC a = e \thenC \skipC \elseC logfail(a,e) \endC
\end{eqnarray*}
If we assume all tests pass, 
then we can interpret it as a post-condition $a=e$,
or in this case: $r = \post\div$.

So basically we have code of the following general form:
\begin{eqnarray*}
   && n := N0 ; \qquad  N0 \in \setof{0,N,-N}  
\\ && d := D0 ; \qquad  D0 \in \setof{0,D,-D} 
\\ && r := n \div d ;
\end{eqnarray*}
with post-condition $r = post(n,d)$
where:
$$
post \in \{ \bot, \abs n \div' \abs d, -(\abs n \div' \abs d)\}
$$


We want to compute the weakest precondition:
$$
  \wp(n := N0 ; d := D0 ; r := n \div d ,r = post)
$$
We can in fact do some pre-computation here:
\begin{eqnarray*}
\lefteqn{\wp(n := N0 ; d := D0 ; r := n \div d ,r=post)}
\EQm{\wp(S_1;S_2,R)}
\\&& \wp(n := N0,\wp(d := D0 ; r := n \div d ,r=post))
\EQm{\wp(S_1;S_2,R)}
\\&& \wp(n := N0,\wp(d := D0,\wp(r := n \div d ,r=post)))
\EQm{\wp(x:=E,R)}
\\&& \wp(n := N0,\wp(d := D0,(r=post[n \div d/r])))
\EQm{\wp(x:=E,R)}
\\&& \wp(n := N0,(r=post[n \div d/r])[D0/d])
\EQm{\wp(x:=E,R)}
\\&& ((r=post[n \div d/r])[D0/d])[N0/n]
\EQ{substitution composition}
\\&& (r=post)[N0 \div D0/r]
\EQ{expression substitution}
\\&& (N0 \div D0)=post[N0 \div D0/r]
\EQ{$r$ not free in $post$}
\\&& (N0 \div D0)=post
\end{eqnarray*}



\subsection{Computing Weakest Preconditions}

\subsubsection{Transition $(\_,DZ) \then UNDEFDIV$}

\begin{eqnarray*}
   N0 &=& \_
\\ D0 &=& 0
\\ post &=& \bot
\\ (N0 \div D0)=post
   &=&
   \_ \div 0\quad=\quad\bot
\\  d = 0 &\implies& \_ \div d = \bot
\end{eqnarray*}


\subsubsection{Transition $(NP,DP) \then ISDIV$}

\begin{eqnarray*}
   N0 &=& N
\\ D0 &=& D
\\ post &=& \abs n \div' \abs d
\\ (N0 \div D0)=post 
   &=&
   N \div D \quad=\quad \abs n \div' \abs d
\\  n>0 \land  d>0 &\implies& n \div d = \abs n \div' \abs d
\end{eqnarray*}


\subsubsection{Transition $(NN,DP) \then NEGDIV$}

\begin{eqnarray*}
   N0 &=& -N
\\ D0 &=& D
\\ post &=& -(\abs n \div' \abs d)
\\ (N0 \div D0)=post
   &=&
   -N \div D\quad=\quad-(\abs n \div' \abs d)
\\  n<0 \land  d>0 &\implies& n \div d = -(\abs n \div' \abs d)
\end{eqnarray*}


\subsubsection{Transition $(NP,DN) \then NEGDIV$}

\begin{eqnarray*}
   N0 &=& N
\\ D0 &=& -D
\\ post &=& -(\abs n \div' \abs d)
\\ (N0 \div D0)=post
   &=&
   N \div -D\quad=\quad-(\abs n \div' \abs d)
\\  n>0 \land  d<0 &\implies& n \div d = -(\abs n \div' \abs d)
\end{eqnarray*}


\subsubsection{Transition $(NN,DN) \then ISDIV$}

\begin{eqnarray*}
   N0 &=& -N
\\ D0 &=& -D
\\ post &=& \abs n \div' \abs d
\\ (N0 \div D0)=post
   &=&
   -N \div -D\quad=\quad\abs n \div' \abs d
\\  n<0 \land  d<0 &\implies& n \div d = \abs n \div' \abs d
\end{eqnarray*}

\subsection{Determining Pre-Post Semantics}

We have five implications, with disjoint antecedents:
\begin{eqnarray*}
               d=0 &\implies& \_ \div d  =  \bot
\\  n>0 \land  d>0 &\implies& n  \div d  =  \abs n \div' \abs d
\\  n<0 \land  d>0 &\implies& n  \div d  =  -(\abs n \div' \abs d)
\\  n>0 \land  d<0 &\implies& n  \div d  =  -(\abs n \div' \abs d)
\\  n<0 \land  d<0 &\implies& n  \div d  =  \abs n \div' \abs d
\end{eqnarray*}
